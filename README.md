## Running the Projects

The repository contains independent projects that use different development environments.

**Java applications**

Java projects can be opened in a compatible development environment such as VS Code, IntelliJ IDEA, or NetBeans.

For standard Java applications with correctly named source files:

```bash
javac ClassName.java
java ClassName
```

Some uploaded Java source files do not currently have `.java` extensions or filenames matching their public class names. These may need to be renamed or reorganized before compilation.

**Visual Basic .NET application**

1. Open the Windows Forms project in Visual Studio.
2. Restore any required project dependencies.
3. Build the application.
4. Run the application using Visual Studio's debugging tools.

**Bash scripts**

Open the script in a Linux environment, save it with a `.sh` extension if appropriate, and execute it using Bash.

```bash
bash script.sh
```

Some exercises require additional input files or specific environments.
